--- title: Structure of the dashboard permalink: /en/help/navigation/ language: en layout: page --- The dashboard comprises four categories, 22 domains and 31 preliminary Beyond-GDP indicators from the Secretary-General’s independent high-level expert group on Beyond-GDP.

Presentation of the individual indicators

For each domain, the available indicators are presented in a chart and a table. For some indicators, the presentation is supplemented by an interactive map showing the data for the Länder. The green buttons below the chart allow you to download the displayed data in CSV format and the chart as a PNG file.

Details and Data sources

TheDetails and Data sources tabs are located at the bottom of each indicator page.
  • The Details tab contains the indicator name, information on the relevant domain and the data state. It also specifies whether the indicator forms part of the set of indicators for the 17 UN Sustainable Development Goals (SDGs). Where necessary, any discrepancies between the Beyond-GDP indicator and the indicator displayed in the dashboard are explained. Further explanations regarding the indicators are also provided. In addition, the tab contains a description of the relevant domain.
  • The Data sources tab contains links to the organisations that provide the data for the respective indicators. Where possible, links to the specific data sources are also provided.
